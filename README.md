# 氦语音实时校正系统 · 饱和潜水通话平台

海上饱和潜水作业中，潜水员呼吸氦氧（Heliox）混合气，氦气中声速远高于空气，
使声道共振峰整体上移、低频段还受舱壁/面罩影响呈非线性位移，形成难懂的"唐老鸭音"。
本系统逐帧估计全极点声道模型，把共振峰按当前舱压对应的声速比拉回正常位置，
**音高（声门振动基频）保持不变**，再合成可懂的语音。

## 技术栈

- TypeScript + Vite 6（严格类型，无第三方运行时 DSP 依赖）
- Web Audio API：`AudioWorkletNode` 承载逐帧实时处理，主线程负责 UI
- Vitest：单元测试与端到端验收

## 信号处理流水线

每个 32 ms 分析窗（512 点 @16 kHz，50% 重叠，16 ms hop）执行：

1. **加窗 FFT**（自实现基-2 Cooley–Tukey）
2. **谱减降噪**：过减法 + 谱下限抑制呼吸阀宽带气流声，低频时间中值滤波压制气泡脉冲，
   800 Hz 以下减弱过减以保护基频与弱 F1
3. **VAD**：基于噪声底信噪比的能量判决，对共振峰上移的氦语音同样有效
4. **音高检测**：归一化互相关 + 抛物线插值 + 倍频/半频纠错，中值跟踪去跳变（仅监测，不修改）
5. **全极点建模**：自相关 + Levinson–Durbin 求 LPC 系数，反射系数钳制保证稳定
6. **共振峰拾取与跟踪**：以 LPC 谱局部峰为主、极对估带宽，跨帧最近邻关联 + 指数平滑
7. **频率搬移**：非线性 warping 函数（含舱壁/面罩 β 低频修正项），二分求逆
8. **频谱域合成**：幅度谱按物理 bin 映射重采样、保留原始相位，动态音高保护带内谱线恒等，
   从机制上保证谐波间距（音高）不变；线性交叉淡化 OLA 输出

### 为什么用频谱域合成而非全极点再合成

原型曾采用"残差激励驱动搬移后全极点滤波器"的经典声码器结构，但谱重采样重建的
自相关在高阶下接近奇异，合成滤波器易出现近单位圆极、自激锁频，反而改变基频周期。
频谱域搬移直接在 STFT 幅度上操作、相位不动，天然保持谐波网格，数值稳健且延迟可控。

## 物理模型

`src/dsp/physics.ts` 基于理想气体声速 `c = sqrt(γRT/M)`，用摩尔分数加权计算
氦氧氮三元混合气的比热比与摩尔质量。校正系数 `s = c_air / c_mix`，
90% 氦气、180 msw 工况下 s≈0.48。理想气体声速只依赖温度与组分，与绝对压力无关；
深度通过各任务阶段的配比进入模型。

## 目录结构

```
src/
  dsp/            纯 DSP 核心（可在 Node 与 Worklet 复用，无 DOM 依赖）
    physics.ts    气体声速与校正系数
    warping.ts    非线性频率搬移（含 β 低频修正）
    fft.ts        FFT / Hann 窗
    lpc.ts        自相关 + Levinson-Durbin
    formants.ts   Durand-Kerner 求根 + 共振峰拾取
    formantTracker.ts  跨帧共振峰跟踪平滑
    pitch.ts      NXC 音高检测 + VAD
    noiseReduction.ts  谱减降噪
    frameProcessor.ts  逐帧流水线（AudioWorklet 与测试共用）
    simulator.ts  氦语音声源模拟器（独立于校正器，供演示与端到端测试）
  worklets/       AudioWorklet 处理器与消息协议
  audio/          主线程 AudioContext 建图
  model/          潜水日志（深度时间轴、潜水员档案、配比计划）与可懂度评估
  ui/             四个页面与画布绘制
  state/          全局状态 store
test/             Vitest 测试
```

## 四个页面

1. **潜水员通话**：音频链路、原始/校正波形、VAD/F0/延迟、模拟通话记录、旁路对比
2. **舱压深度**：实时深度剖面曲线、声速、校正系数 s、氧分压、任务阶段与事件日志，
   时间轴可拖动，校正系数随潜水日志自动跟随
3. **共振峰显示**：LPC 全极点谱、He/空气共振峰标记与带宽、F1–F4 时间序列、元音空间轨迹
4. **通话记录**：逐条通话事件、导出 JSON、离线清晰度评估（20 词测试词表）

## 验收指标与测试

```bash
npm test        # 35 个测试
npm run build   # 类型检查 + 生产构建
```

端到端测试覆盖三个深度（60/180/200 msw）与四个潜水员嗓音：

- **共振峰精度**：校正后 F1/F2 与空气参考的平均误差 ≤10%（实测多在 1–5%）
- **可懂度**：20 词清晰度测试，校正后识别率相对未校正提升 ≥2 倍
  （未校正几乎为 0，校正后多数工况 100%）
- **延迟**：32 ms 算法缓冲 + 典型 <20 ms AudioContext 基线，总预算 <60 ms；
  P95 单帧处理耗时 <10 ms hop
- **音高保持**：残差/谱线不重采样，输出 F0 与输入偏差在工程容差内
- **数值稳定**：反射系数钳制、谱下限、有限值防护，长时间运行无 NaN/直流漂移
