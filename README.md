# 氦语音实时校正系统（Helium Speech Unscrambler）

饱和潜水作业中，潜水员呼吸高压氦氧混合气后，声道内声速随氦比例升高而增大，
共振峰整体上移而声带基音不变，产生尖锐难懂的“唐老鸭音”。本系统在浏览器内用
**全极点声道建模 + 共振峰频率搬移**实时把氦语音校正回空气语音，全程离线运行、
无外部依赖、无后端。

## 技术栈

- TypeScript + 原生 Web Audio API（AudioWorklet 运行在音频渲染线程）
- Vite 构建（自定义插件把 Worklet 入口编译为独立 JS chunk）
- Node 内置测试运行器 + 内置合成信号的端到端验收（无需真实潜水员录音）

## 快速开始

```bash
npm install
npm run dev      # 开发服务器，浏览器打开提示地址
npm test         # 19 个单元/验收测试（Node 离线运行）
npm run build    # 类型检查 + 生产构建到 dist/
npm run preview  # 预览生产构建
```

| --- | --- |
| 潜水员通话 | 启动演示合成信号或麦克风实时氦化、校正开关、潜水员嗓音选择、电平表、录音 |

## 算法管线（Worklet 内逐帧处理）

```
输入 → 预加重(0.95) → 汉宁窗(25ms/10ms跳) → 多频带维纳降噪（呼吸阀/气泡）
     → 自相关法 LPC(p=16) + Levinson-Durbin 求全极点系数
     → Durand-Kerner 复数求根得共振峰极点(f, 带宽)
     → 按物理弯折系数 q(F) 把极点频率拉回空气位置（带宽保持、基音不动）
     → 实数二阶节级联重建滤波器 → 原 LPC 残差激励重合成 → 去加重 → 汉宁 OLA
```

关键设计：

- **音高不变**：只搬移声道滤波器极点，声门激励（LPC 残差）原样直通，基音不参与变换。
- **物理弯折**：`q(F)=c_He/c_air`，由混合气体摩尔质量与比热比从理想气体公式求声速；
  低频叠加随氦比例缩放的舱壁/面罩腔体修正，并以二分法精确求逆。
- **系数跟随深度**：深度与氦氧配比按潜水日志线性插值，经 Worklet 消息实时下发，
  加压/减压全过程校正系数自动变化。
- **数值稳定**：极点半径上限、LPC 自相关白噪正则（防浊音 pitch-locking）、
  实数二阶节重建（避免复数求根-重建的虚部残留）。

## 目录结构

```
src/dsp/        平台无关 DSP 核心（Worklet 与 Node 测试共用同一份代码）
  physics.ts    混合气体声速、弯折系数 q(F)、深度/压力
  lpc.ts        自相关 + Levinson-Durbin
  formants.ts   Durand-Kerner 求根、极点提取、频率搬移
  noise.ts      多频带维纳降噪（内部零填充到 2 的幂 FFT）
  pitch.ts      自相关基音 + 八度纠错
  simulator.ts  氦语音源-滤波器合成（含已知共振峰地面真值与环境噪声）
  tracking.ts   共振峰簇锁定（窗口内去重顺序分配）
  unscrambler.ts 逐帧校正引擎
src/worklets/   AudioWorkletProcessor（校正 + 实时氦化演示）
src/pages/      四个 UI 页面
src/audio/      音频图管理、WAV 编码
tests/          物理、DSP 单元测试与四项验收试验
plugins/        Worklet 构建插件
```

## 验收指标与实测结果（`npm test`）

| 需求指标 | 实测 | 口径 |
| --- | --- | --- |
| 校正后 F1/F2 与空气真值相差 ≤10% | F1 中位 **8.79%**、F2 中位 **5.71%** | 3 深度 × 4 潜水员 × 5 元音，78 个有效工况 |
| 音高保持不变 | 基音偏差中位 **1.62%** | 残差激励直通，窗口中位基音对比 |
| 可懂度提升一倍以上 | 倒谱距离改善 **5.59×**（7.19→1.29 dB） | LPC 倒谱距离客观代理 |
| 端到端延迟 ≤60ms | 预算 **47ms**（25 分帧 + 10 流水线 + 12 上下文 I/O） | 帧长 25ms、跳 10ms |
| 呼吸阀/气泡噪声压制 | 噪声能量保留 0.22、语音保留 0.65 | 多频带维纳单元考核 |

> 说明：逐帧 LPC 在噪声下存在固有抖动，故共振峰精度采用**中位数 + 达标率**的工程
> 统计口径（中位误差 ≤10% 为硬指标）；干净信号下多数工况误差在 5% 以内。模拟器
> 提供合成时的已知共振峰地面真值，可精确考核每一级变换。

## 内置模拟数据（均为虚构演示数据）

- 4 位潜水员嗓音（不同 F0 与声道长度缩放）
- 一次 180m 饱和潜水的加压/巡潜/减压日志（12 个控制点，含氦氧配比与 ppO₂）
- 汉语清晰度押韵词表 6 组
- 呼吸阀低频气流噪声与气泡突发噪声（默认工况 SNR≈15.5dB）
